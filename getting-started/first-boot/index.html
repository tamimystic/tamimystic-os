    First Boot and Web Dashboard Walkthrough

    Once flashing is complete, Tamimystic OS starts immediately upon reboot. This guide explains what happens during boot, how to connect to the serial console, and how to access the Web Dashboard.

    1. Serial Monitor Output (@ 115200 Baud)

    Open your favorite serial terminal (e.g., PuTTY, Arduino Serial Monitor, idf.py monitor, or VS Code Serial Monitor) and configure it to: * Baud Rate: 115200 * Data Bits: 8 * Parity: None * Stop Bits: 1

    2. Connecting to the Web Dashboard

    Tamimystic OS hosts a high-performance, asynchronous web application directly from flash:

    Step 1: Connect Wi-Fi

    Using the serial CLI, connect the OS to your local Wi-Fi network: 

    aeron> wifi "MyHomeNetwork" "MySecretPassword"
    The OS outputs: 
    [NET] Connecting to Wi-Fi...
[NET] Wi-Fi Connected. Got IP: 192.168.1.142
[SYS] Network is now CONNECTED!

    Step 2: Open Dashboard in Browser

    Open your web browser (Chrome, Firefox, Safari, Edge) on your phone, tablet, or PC and navigate to: 

    http://192.168.1.142/

    3. Dashboard Features Overview

    The Web Dashboard is organized into 5 primary panels:

    graph TD
    DASH["Web Dashboard (http://&lt;device-ip&gt;/)"]
    DASH --> P1["1. Robotics Command Center (Kinematics, D-Pad, 6-DOF Arm Sliders)"]
    DASH --> P2["2. Edge AI Live Stream (MJPEG Camera View, Bounding Boxes, Model Selector)"]
    DASH --> P3["3. Plug and Play Matrix (Live I2C Sensor List and Dynamic Pin Re-assignment)"]
    DASH --> P4["4. In-Browser Python IDE (Code Editor, Live Console and 6.8MB File Manager)"]
    DASH --> P5["5. Dual-Bank OTA Manager (Upload Firmware .bin and Rollback Monitor)"]
    1. Universal Robotics:
    2. Live D-Pad virtual joystick for Differential and Mecanum holonomic strafing.
    3. 6-DOF Robotic Arm joint angle sliders (\(J_1 - J_6\)) with real-time degree feedback.
    4. Interactive \((X, Y, Z)\) Cartesian Inverse Kinematics target input.
    5. Emergency Stop (E-Stop) and Safety Auto-Braking indicator.
    6. Edge AI and Vision Stream:
    7. Real-time video stream from OV2640 / OV3660 camera.
    8. Overlaid neural bounding boxes with class labels and confidence percentages.
    9. Model switcher (Person Detector, Object Detector, Lane Follower, Gesture Classifier).
    10. Auto-Follow Target toggle.
    11. Plug and Play Hardware Matrix:
    12. Interactive table showing all detected I2C sensors with physical addresses and status.
    13. Visual software pin matrix: Click any pin (e.g., MOTOR_L_PWM or I2C_SDA) and assign it to another GPIO without restarting.
    14. Web Python IDE:
    15. Full code editor with syntax highlighting.
    16. Direct execution button (Run Script) and Stop button.
    17. Live stdout console streaming print outputs in real-time.
    18. Flash file manager to view and delete files in the 6.8MB LittleFS partition.
    19. Dual-Bank OTA:
    20. Single-click binary firmware upload with automatic slot switching and rollback arming.
